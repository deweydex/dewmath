Find out where a maths class is starting from.

dewmath is a small set of tools for teaching mathematics in further education. The first of them is a readiness diagnostic for QQI Level 5 Mathematics for IT and Computational Methods: a teacher configures it in a browser, students sit it from a link, and every wrong answer is read as a particular misunderstanding rather than as a mark lost.

Build a diagnosticAnalyse a class

How it works

Configure

Choose what to ask

Pick skills across three levels, foundation, core and advanced, set the wording, the order, a time limit and a question cap. Everything is packed into a short link. There is no server and no account.

Sit

Students answer from the link

One question at a time, all on one page, or a few per page, with an "I don't know" option and an optional confidence check. Answers save as they go. At the end each student downloads a small results file.

Read

Open the files together

The analysis page groups the class by readiness, ranks the skills to teach first, charts the most common misconceptions, and writes a short report card for each student. Nothing leaves the browser.

Stages

  • doneReadiness diagnostic. Tagged distractors, three levels, share links, class analysis, sample class, display settings including a dyslexia-friendly font.
  • nextItem authoring in Markdown. A plain-text format for questions, with LaTeX, that compiles into the bank so that colleagues can contribute items without touching the code.
  • laterAdaptive flow. Choosing the next question from the answers so far, so a strong student is not asked forty foundation items and a struggling one is not sent through calculus.
  • laterSubmission without files. Results posted straight to a shared store, so students do not need to handle a download.

About

dewmath is built by Joshua Aaron, a further education lecturer in Dublin, for the maths and computing modules he teaches. This page is its home; the tools, their earlier stages and the sample data will collect here as they are made. Questions, corrections to items and offers of new questions are welcome on GitHub.
